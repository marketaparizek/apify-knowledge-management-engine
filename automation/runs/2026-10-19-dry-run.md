## What the run taught us

1. **Owner-left status gets overwritten.** Step 2 sets Needs review when an owner leaves. Next Monday step 1 recomputes the status from the review date and sets it back to Up to date. Fixed in the prompt: step 2 writes "Owner left" into Bot note, and step 1 keeps Needs review while that note is there.
2. **Personal pages with no key page slip through.** Brand guidelines sits in a personal space, but no registry row covers brand, so the duplicate search never looks for it, and the walk only checks titles and working-doc paths. Fixed in the prompt: the walk also flags pages whose path matches PERSONAL_PAGE_PATHS.
3. **Keyword search matches body text, not titles.** Searching "notes" returned the pilot page and the page standard, because they mention notes. The title check in step 4 is what keeps them out of the queue. Keep it.
4. **The "Mark as reviewed" button can't be created through the API.** Notion returns `Property type "button" is not supported for updates`. It has to be added once by hand in the registry: add property → Button → "Mark as reviewed" → action "Edit property" → Last reviewed → Now. Until it exists, the reminder DM points to a button that isn't there.
5. **The Slack lookup works for the owner check.** The connector returns `user_not_found` for a missing ID, which is all step 2 needs.
